# Project Name
Shop Demo
# Features
- Search for products in a gallery
- Disply product details
- Add product to cart
- Checkout cart
# Techonologies
- Core Web
- React
- Django 
- REST API
# Infrastructure
### Media Storage
- **Provider:** Amazon AWS S3
- **Purpose:** Store product and category images.
- **Integration:** Django manages image references; React displays images using URLs provided by the API.
- **Hosting:** S3 operates independently of Render.
